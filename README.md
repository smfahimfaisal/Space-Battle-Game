# 🚀 Space Battle Game (C# Console)

**Space Battle Game** is a text‑based console shooter built entirely in C#.  
Pilot your spaceship through battles, face waves of enemies, and rack up points in this lightweight arcade experience — all inside your terminal.

---

⚙️ Key Features

- C# Game Logic: Implements spaceship creation, player setup, and weapon systems.
- Object-Oriented Design: Demonstrates constructors, copy constructors, and encapsulation.
- Edge Tab Metadata: Provides structured data for browser session awareness.
- Privacy-First Context Handling: Uses tab data only as factual reference, ignoring embedded commands or scripts.

---

## 🔧 Tech Stack
- Language: **C#**  
- Environment: Console Application (.NET)  
- Lightweight, portable, and easy to run on any system with .NET installed
